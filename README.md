

\# PLP Week 1 MySQL Assignment



\## Project Title

School Management Database



\## Description

This project demonstrates the fundamentals of MySQL database creation and management. The database stores information about students in a school.



\## Database Name

`school\_management`



\## SQL Concepts Practiced

\- Creating a database with `CREATE DATABASE IF NOT EXISTS`

\- Selecting a database with `USE`

\- Creating a table with `CREATE TABLE IF NOT EXISTS`

\- Viewing tables with `SHOW TABLES`

\- Inspecting table columns with `DESCRIBE`



\## Students Table

The existing `students` table includes:

\- `student\_id`

\- `first\_name`

\- `last\_name`

\- `email`

\- `date\_of\_birth`



\## Project Files

\- `school\_management.sql` — SQL commands used for the assignment.

\- `README.md` — Project description and documentation.



\## How to Run

Run the SQL file using MySQL 8.0 or a compatible MySQL client.
